# Beat-Grid Event Sync — Musical Transitions (2026-09-11)

GRADES spec=4 design=4 correctness=4 quality=4; biggest gap: verified by boundary-exact numeric assertions on the audio-clock grid, not by listening — sample-accurate alignment is proven, the perceived smoothness of the new seams is not.

## What changed (index.html)

Gameplay events that change the music now land on the sequencer's **existing bar grid** instead of tearing it mid-bar. Previously: `setAmbient()` reset `musicStep=0`/`_nextTime=null` on every wave start, and the boss flip nulled `_nextTime` — both re-rastered the grid at `now+50 ms`, an audible phase seam on every transition.

New in `AudioSys`:

- **`requestSwitch(fn, tag?)`** — queues a song/layer change; fired at the next **bar boundary** (every 16th step of the 16th-note grid). Tag dedupes (the boss condition stays true until the boundary fires, so per-frame re-queuing is safe).
- **`setAmbientCore(id)`** — the whole body of the old `setAmbient` (reverb IR, drone, filter/pump resets) *without* touching `musicStep`/`_nextTime`. Legacy `setAmbient(id)` keeps the hard reset for the title path; runs use **`setAmbientKeepGrid(id)`** (no-op when the arena — and therefore the song — is unchanged).
- **`beatAt(fn, minBars)`** — boundary-timed one-shot events with **relative** `minBars` (measured from the *queue* bar; an absolute comparison would fire immediately at high bar counts — probe-caught API bug, fixed before shipping).
- **`waveStinger(at)`** + `_toneAt` — a short triangle riser + sub thump voiced on the music bus at the bar line (`startWave` queues it via `beatAt`); part of the piece, not a jingle.
- Scheduling order in `tickMusic`: fire switches → fire boundary events → **`break` before scheduling that step**. `_chipTick` receives a frame-local `boss` param and reads the song table inside, so scheduling the boundary step after a switch would mix one stale 16th into the new bar; breaking instead means the next frame re-reads `boss`/song/bpm fresh and schedules the *same audio timestamp* — sample-accurate, no drift, no lost step.
- No-music paths (music off, paused, title, not started) **flush** pending switches immediately — nothing to sync to; queued stingers simply never fire (no orphaned scheduled nodes).
- `endRun` / `startRun` call `resetTransitions()` — a wave's queued events die with the wave; a fresh run starts clean.

## Hook sites

- `Game.startWave` → `AudioSys.setAmbientKeepGrid(this.arena.id)` + `AudioSys.beatAt(a => a.waveStinger(at))`.
- Boss flip (`Game.update`) → `requestSwitch(a => { a.bossMode = want; a._song = null; }, 'boss')` instead of `_nextTime = null`.
