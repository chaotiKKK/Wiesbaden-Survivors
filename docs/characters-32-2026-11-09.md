## Zählung und Freischaltung

Vorher zählten Titel, Codex und das `allChars`-Achievement `Save.data.unlockedChars.length`. Figuren ohne `unlock`-Bedingung sind aber auswählbar, ohne in diesem Array zu stehen; dadurch zeigte der Titel **3/32**, obwohl **28** Figuren im Grid wählbar waren, und `allChars` konnte nie wahr werden.

Die zentrale Abfrage liegt jetzt in `Save`:

```js
isCharUnlocked(id) {
  const c = CHAR_BY_ID[id];
  return !!c && (!c.unlock || this.data.unlockedChars.includes(id));
}
unlockedCharCount() {
  return CHARS.reduce((n, c) => n + (this.isCharUnlocked(c.id) ? 1 : 0), 0);
}
```

Verwendet von Charakter-Grid, Titel, Codex, `selectChar`/`restoreSavedChars`, dem UE-Export und beiden `allChars`-Pfaden. Die vier expliziten Sperren bleiben unverändert; `unlockedChars` speichert weiterhin nur die tatsächlich freigeschalteten IDs. Keine Save-Migration nötig.
